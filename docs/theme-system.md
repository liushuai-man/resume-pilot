# ResumePilot 主题颜色系统

## 设计目标

主题切换只改变颜色值，不改变组件结构。组件不再依赖 `#FFFFFF`、`gray-100` 等视觉值，而是使用能够表达用途的语义令牌。

ResumePilot 保留“求职证据工作台”的冷静绿色视觉：品牌绿只用于操作、焦点和选中状态；页面背景、内容表面和浮层表面形成三级层次；简历预览始终保持打印纸张语义，不跟随应用主题反色。

## 令牌层级

| 语义 | Tailwind 类示例 | 用途 |
| --- | --- | --- |
| 页面 | `bg-canvas` | 应用最底层背景 |
| 表面 | `bg-surface` | 导航、卡片、侧栏 |
| 次级表面 | `bg-surface-muted` | hover、分组区、编辑工作区 |
| 浮层 | `bg-surface-raised` | 菜单、弹窗、浮动面板 |
| 边框 | `border-border` | 常规分隔线 |
| 强边框 | `border-border-strong` | 控件 hover、强调分隔 |
| 主文字 | `text-ink` | 标题、正文、关键数据 |
| 次文字 | `text-muted` | 描述、非激活导航 |
| 弱文字 | `text-subtle` | 辅助信息、时间、占位提示 |
| 品牌 | `bg-brand` / `text-brand` | 主操作、选中、焦点 |
| 品牌弱底 | `bg-brand-soft` | 选中项与轻强调背景 |

颜色值定义在 `src/styles/global.css`，Tailwind 映射定义在 `tailwind.config.js`。使用 RGB 通道变量是为了让 `bg-surface/95` 等透明度语法正常工作。

## 使用规则

1. 新组件禁止直接写十六进制主题色，也不要用 `bg-white` 表达应用表面。
2. 颜色名称描述职责，而不是亮度，因此深浅主题中的组件代码完全一致。
3. 状态色单独使用 `brand`、`danger`、`warning`，不要从表面颜色推导。
4. 简历预览、导出和打印区域使用 `data-theme-exempt="true"`，保持文档原色。
5. 旧页面暂由 `global.css` 中的兼容桥接规则覆盖，迁移完成后删除该桥接层。

## 迁移顺序

`应用骨架与导航 → 通用组件 → 页面卡片与侧栏 → 表单和浮层 → 删除旧颜色桥接规则`

每迁移一个模块，应同时检查浅色、深色、键盘焦点、hover、禁用状态以及简历预览是否保持原色。
