# ResumePilot V2.0 功能清点

本文用于 V2.0 集中产品测试。状态以当前代码、数据库迁移和自动验收结果为准；完整操作步骤见 [V2.0 集中验收清单](./v2-acceptance-checklist.md)。

## 1. 简历基础能力

- [x] 统一 `ResumeDocument` 数据结构，兼容旧简历内容迁移
- [x] 首页缩略图、编辑器、面试只读预览和打印页复用预览内核
- [x] classic、modern、minimal、sidebar 四种模板
- [x] A4 分页、列表跨页、超高条目保留和 PDF 导出
- [x] 模板字号、边距、颜色与布局配置
- [x] PDF、DOCX 上传及结构化简历入口

## 2. 目标岗位与岗位画像

- [x] JD 新增、列表、选择和删除
- [x] AI 提取岗位名、职级、行业、职责、必备能力、加分项和关键词
- [x] 要求绑定 JD 原文证据并拒绝虚假证据
- [x] 低置信度提示、人工编辑、保存和确认
- [x] 岗位画像版本历史、当前确认版本和历史只读状态
- [x] 保存模型、Prompt、Parser 和画像版本
- [ ] 使用有效模型完成初级、中级、高级三岗位产品校准

## 3. 简历评价

- [x] 确定性 ATS 结构分，从 0 分按证据加分
- [x] 字段完整性、解析性、日期、乱码、占位和重复文本检查
- [x] AI 内容质量五维评价、字段证据和置信度
- [x] 基于 confirmed JobProfile 的岗位匹配与逐项要求结论
- [x] ATS、内容质量和岗位匹配三类分数独立展示
- [x] 简历或岗位画像变化后旧报告过期提示
- [x] 问题跳转到具体 `section / item / field`

## 4. 定向优化与恢复

- [x] 从 ATS、内容质量和岗位匹配问题生成字段级建议
- [x] 缺少事实时先追问，拒绝模型补造经历或量化结果
- [x] 建议编辑、恢复 AI 原文、拒绝、采纳与安全应用
- [x] 服务端签名 suggestion token，防止伪造拒绝样本
- [x] 应用前事务快照、字段并发保护和应用后独立重评
- [x] 优化历史按来源/状态筛选和分页
- [x] 展示修改前后文本、原因、证据、分数变化和解决状态
- [x] 一键撤销、重复撤销保护和后续编辑冲突保护

## 5. 模拟面试 Agent

- [x] 通用岗位与 confirmed JobProfile 两种面试目标
- [x] 冻结简历、岗位画像、Rubric 和 InterviewPlan
- [x] 每题关联能力维度，按覆盖缺口规划下一题
- [x] 回答阶段只保存问答，不显示或调用正式评价
- [x] 全部回答结束后一次批量评价并确定性聚合报告
- [x] 回答 `submissionId` 幂等与下一题独立重试
- [x] 报告 checkpoint、输入哈希、节点状态和单步重试接口
- [x] 生成中、失败、完成状态及历史页轮询
- [x] 刷新恢复活动面试、当前题位、问答和待生成状态
- [x] 简历、岗位要求、问答记录和临时笔记工作台面板
- [x] 报告总览、维度分、覆盖题数和逐题回顾
- [x] 模型、Prompt、Rubric、调用次数、checkpoint 复用和耗时审计
- [x] 薄弱项返回简历补证据或进入专项训练
- [ ] 使用有效模型完成人工故障注入与所有失败节点产品验收
