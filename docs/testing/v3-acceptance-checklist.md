# ResumePilot 3.0 集中验收清单

**产品范围：** [3.0 产品设计与范围基线](../product/v3-product-spec.md)  
**实施路线：** [3.0 实施路线图](../roadmap/v3-roadmap.md)

## 1. 验收规则

- 每项结果只允许标记为 `通过 / 失败 / 阻塞 / 不适用`，并附日期、环境、执行人和证据链接
- 自动测试通过不能替代浏览器交互、真实模型校准、音频设备测试和故障注入
- 使用模拟模型只验证协议和失败恢复，不能证明真实输出质量
- 未执行的项目不得因“代码已实现”标记通过
- 阻断级和高风险缺陷必须清零；不适用项必须说明依据
- 验收使用经授权可发送至相应模型或语音供应商的数据

## 2. 测试环境与样本

至少准备：

- 新注册用户、已有 V2 数据用户、第二个隔离用户
- 3 个不同职级/方向的 JD 及已确认 JobProfile
- 2 份岗位专属简历、1 份空壳简历、1 份两页以上长简历
- 每个岗位至少 2 场有效面试，以及一场中途失败的面试
- 中文、英文、中英混合、包含技术术语的语音样本
- 安静环境、背景噪声、短回答、超长回答和静音录音
- 可成功和可故障注入的 LLM、ASR、TTS 配置

记录浏览器、操作系统、麦克风设备、模型/供应商、版本、网络环境和部署提交号。

## 3. M0：基线与可观测性

- V2 自动回归、生产构建和现有集中验收没有新增回归
- 数据迁移在旧数据副本上成功；失败回滚或修复路径经过演练
- 核心请求包含关联 ID，AI 流水线能按任务还原阶段和错误
- 事件可计算创建目标、开始行动、完成行动、完成面试和查看报告
- 重复事件不会造成核心指标重复计数
- 日志抽查不包含密码、JWT、模型密钥、完整简历、完整 JD、完整回答或音频正文
- feature flag 关闭后，新功能入口隐藏且 V2 主路径仍可用

## 4. 岗位工作空间

### 主路径

- 新用户创建目标岗位、确认画像、关联简历并进入工作空间
- 已有 V2 岗位和简历可以进入或建立工作空间，不要求重新录入正文
- 工作空间正确展示岗位、当前简历、画像状态、三类诊断、优化和面试记录
- 从工作台进入编辑、分析或面试后，返回时仍处于原岗位上下文
- 无数据、加载、部分失败、全部失败和无权限状态均有明确呈现与恢复入口

### 隔离与一致性

- 两个岗位关联不同简历时，报告、行动和面试记录不会串联
- 第二个用户不能读取、修改或推断第一个用户的工作空间及子资源
- 切换当前简历后，依赖旧简历的报告和行动正确标记过期
- 确认新 JobProfile 后，旧画像驱动的匹配、面试计划和行动正确标记过期或历史状态
- 删除岗位、简历、报告和取消关联均符合已定义保留策略，不产生可访问孤儿资源
- 同一写请求重复提交不会重复创建关联、报告或历史事件

## 5. 行动闭环

- ATS、内容质量、岗位匹配和面试弱项均能创建有来源的行动
- 行动包含原因、证据、目标对象、优先级解释和明确完成条件
- 工作台最多展示 3 个优先行动，并允许查看全部行动
- 用户可以开始、完成、忽略行动；状态刷新后保持一致
- 相同来源和目标的重复请求不会创建重复有效行动
- 上游简历、画像或报告变化后，旧行动变为过期且不能误应用
- 完成字段优化行动后运行正确的重评，展示问题是否解决而非只显示总分
- 验证失败时行动不被伪装为已解决，用户可以重试
- 缺少事实时系统要求用户补充或保留缺口，不生成虚构事实
- AI 建议应用前创建快照；撤销后内容、行动和效果记录一致
- 可从正式数据计算行动开始率、完成率、问题解决率、撤销率和过期率

## 6. 成长画像

- 少于最小有效样本量时明确展示样本不足
- 同一画像的多场面试产生可比较趋势，不同画像默认隔离
- 每项能力结论可以展开至场次、题目、回答证据和 Rubric
- 低置信度结果不会显示为确定性长期结论
- Rubric、模型或画像版本不可比时显示趋势断点
- 删除面试后聚合结果重新计算，已删除证据无法通过旧链接访问
- 从薄弱项创建专项训练后，新面试计划优先覆盖相应能力
- 专项训练完成后生成新证据，但系统不会用文案保证分数必然上升

## 7. 语音面试

### 权限与设备

- 麦克风授权成功后能录制、试听、重录和提交
- 用户拒绝或撤销权限时有明确说明，并可切换文字模式
- 没有可用输入设备、设备被占用和播放失败时不会卡死页面
- 页面不会在未发生明确用户操作时开始录音

### 录音、上传和恢复

- 支持规定范围内的格式、大小与时长；超限在上传前后均被拒绝
- 伪造 MIME、损坏文件、空录音和超长静音不会进入正式评价
- 上传进度、取消、失败重试和成功状态明确
- 刷新或关闭页面不会继续后台录音；重新进入后恢复到安全可理解状态
- 网络中断后不会产生重复音频、重复答案或跳过题目
- 用户无法访问其他用户的音频资源；音频不存在永久公开链接
- 失败分片和无主临时文件按策略清理

### 转写与回答确认

- 中文、英文、中英混合和技术术语样本完成真实服务校准并记录结果
- 转写原文与用户修正文本分开保存，报告明确使用确认文本
- 用户未确认转写时不能进入正式内容评价
- 转写失败可以重试或切换文字输入，已录音状态和删除选项明确
- 同一音频重复回调或重复提交不会创建重复答案

### 提问播报与降级

- 文字问题先于或同时于语音可见，不因 TTS 延迟阻塞
- TTS 超时、失败或不可用时可以继续阅读文字并回答
- 重复播放不会重复生成题目或推进题位
- 语音播放和录音不会同时造成不可控回声；无法自动处理时给出耳机提示

### 报告与公平性

- 内容评价与语音表现评价分开展示和存储
- 内容评价只使用用户确认文本，不因 ASR 原始错误扣分
- 语音指标与源音频可复算：时长、语速、静音段、已配置口头禅
- 报告不评价口音，不推断情绪、人格、诚信、健康或受保护属性
- 音频质量不足时标记指标不可用，不输出伪精确分数
- 语音弱项可以生成有明确完成条件的专项行动

### 删除与生命周期

- 用户删除原始音频后，播放接口和旧资源地址均不可访问
- 删除音频不会意外删除用户明确选择保留的确认文本和面试报告
- 依赖音频的指标在删除后标记不可复算或按既定策略删除
- 删除账户后，音频、临时分片、转写和关联索引按策略清理并可审计

## 8. AI 安全、版本与失败恢复

- 所有正式分析保存输入哈希、模型、Prompt、评分器和 Rubric 版本
- 模型引用的简历与 JD 证据能在对应不可变输入中定位
- 模型输出结构错误、证据虚构、超时、限流和鉴权失败不会写入正式成功结果
- 低置信度结果进入待确认，不自动修改内容或完成行动
- 简历并发编辑时，旧建议不能覆盖新内容
- 面试题目生成、回答保存、评价、报告聚合和发布分别进行失败注入并可从正确节点恢复
- 重试不会重复扣减业务额度或生成重复正式记录
- 关闭某一 AI/语音供应商后，历史正式记录仍可查看

## 9. 性能、成本和容量

- 记录普通聚合接口、工作台首屏、AI 长任务、音频上传、ASR 和 TTS 的 P50/P95
- 工作台打开不会触发新的大模型调用
- 20 场以上历史面试和 100 条以上行动时，分页或增量加载可用
- 并发音频上传和 AI 任务达到预设测试量时，无数据串扰和不可恢复队列积压
- 超时、速率限制和单用户并发限制行为明确
- 可按用户、工作空间和供应商统计模型调用量、音频分钟数与估算成本
- 超过预算或供应商异常时可以通过 feature flag 降级，不影响简历基础能力

具体阈值在 M0 基线后写入验收记录；未设阈值前不得将性能项标记通过。

## 10. UI、移动端与可访问性

- 桌面端完成“创建目标—关联简历—执行行动—验证—语音面试—查看报告”全流程
- 至少一种移动浏览器完成查看工作台、录音首题、确认转写和恢复任务
- 关键操作可通过键盘完成，焦点顺序和模态框焦点恢复正确
- 输入框、录音、播放、进度和错误控件具有可识别标签
- 状态与分数不只依赖颜色表达；浅色和深色主题均可读
- 长任务离开页面前说明是否会继续、如何恢复以及数据是否已保存
- 空状态只提供与当前阶段相关的主要下一步，不堆叠无效入口

## 11. 安全与隐私

- API 对工作空间、行动、报告、音频和删除操作执行服务端所有权校验
- 上传限制扩展名、MIME、魔数、大小和时长，文件名不直接用于存储路径
- 录音前显示用途、保存策略、第三方处理提示和删除入口
- 模型密钥加密存储且任何读取接口不返回明文
- CORS、Cookie/JWT、限流和生产错误响应符合部署安全配置
- 日志、事件和错误追踪抽样确认无敏感正文泄露
- 数据导出与账户删除覆盖工作空间、行动、报告、转写、音频和临时资源

## 12. 发布门禁

以下条件全部满足后才允许发布 3.0：

- 前后端类型检查、生产构建和核心自动回归全部通过
- M0–M5 的退出标准均有验收记录
- 桌面端主路径、移动端最小路径和旧用户迁移通过
- 至少一个真实 LLM、ASR 和 TTS 配置完成质量校准
- 关键失败节点与供应商不可用完成故障注入
- 隔离、并发、幂等、删除和过期规则测试通过
- 阻断级和高风险缺陷为 0
- 完成至少一轮真实目标用户试用并记录改进决定
- 产品负责人逐条确认 [3.0 发布定义](../product/v3-product-spec.md#9-30-发布定义)

## 13. 验收记录模板

| 字段 | 内容 |
| --- | --- |
| 验收项 | 对应章节与检查项 |
| 结果 | 通过 / 失败 / 阻塞 / 不适用 |
| 日期与环境 | 时间、部署、提交、浏览器/设备 |
| 数据与版本 | 样本、模型、Prompt、Rubric、ASR/TTS |
| 证据 | 测试输出、截图、录屏、日志或报告链接 |
| 缺陷 | 编号、级别和影响范围 |
| 复测 | 修复提交、复测结果与日期 |
| 备注 | 边界、风险与后续决定 |
