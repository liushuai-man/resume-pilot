# 简历定向优化

## 目标

用户从 ATS、内容质量或岗位匹配问题进入具体字段，补充真实事实、审阅建议并明确采纳或拒绝。系统不得把 JD 内容当作候选人事实。

## 当前能力

- 支持 ATS 可定位字段、内容质量问题和岗位匹配“证据不足”问题。
- 缺少真实事实时先追问，不调用模型编造经历。
- 建议可手动调整、采纳或拒绝。
- 应用前创建底层快照，字段变化时拒绝覆盖，应用后可以撤销。
- 内容质量和岗位匹配应用后自动重新分析；ATS 应用后同步执行确定性重评分。
- `ResumeOptimizationAction` 记录来源、字段、修改前后文本、采纳/拒绝/撤销状态、评分变化和问题是否解决。

## 产品边界

- 真正的能力缺口、模块缺失和聚合结构问题没有唯一字段落点，进入普通编辑流程，不自动补写。
- 快照是恢复机制，不向用户暴露通用版本树、分支或完整 JSON 差异。
- 用户界面以“优化历史与恢复”呈现，而不是“版本管理”。详见 [ADR-001](../decisions/ADR-001-optimization-history-over-version-management.md)。

## 验收指标

- 建议采纳率
- 采纳后问题解决率
- 撤销率
- 模型编造事实拦截率
