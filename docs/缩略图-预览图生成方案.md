# 简历模板预览页与缩略图方案设计

## 一、设计目标

为简历模板系统提供：

* 模板列表缩略图展示
* 模板详情预览图展示
* 模板编辑器实时预览
* 后续 PDF 导出复用渲染链路

实现效果：

```text
模板
+
演示数据
↓
渲染HTML
↓
生成预览页
↓
截图
↓
生成预览图
↓
压缩
↓
生成缩略图
```

---

# 二、核心概念

## 2.1 模板（Template）

模板负责定义：

* 页面布局
* 模块顺序
* 颜色主题
* 字体样式

示例：

```json
{
  "schema": {},
  "styleConfig": {}
}
```

---

## 2.2 演示数据（PreviewData）

用于生成模板展示效果。

不使用真实用户数据。

示例：

```json
{
  "name": "Alex Chen",
  "email": "alex@example.com",
  "phone": "+86 13800000000"
}
```

---

## 2.3 预览页（Preview Page）

预览页本质为 React 页面。

路由：

```text
/template-preview/:id
```

示例：

```text
/template-preview/modern-blue
```

渲染逻辑：

```text
Template
+
PreviewData
↓
ResumeRenderer
↓
HTML
```

用途：

* 模板预览
* 截图源页面
* PDF 导出页面

---

## 2.4 预览图（Preview Image）

通过截图生成。

尺寸：

```text
1200 × 1697
```

比例：

```text
A4
210 : 297
```

格式：

```text
WebP
```

用途：

* 模板详情页
* 模板市场展示
* 分享展示

---

## 2.5 缩略图（Thumbnail）

由预览图压缩生成。

尺寸：

```text
300 × 424
```

格式：

```text
WebP
```

用途：

* 模板列表
* 模板选择器
* 推荐模板

---

```prisma
model ResumeTemplate {
  id            String   @id @default(uuid())

  name          String

  description   String?

  schema        Json

  styleConfig   Json

  previewData   Json

  previewUrl    String?
```

# 五、前端实现

## 5.1 预览页面

新增路由：

```text
/template-preview/:id
```

页面职责：

* 根据模板 ID 获取模板配置
* 获取 PreviewData
* 渲染完整简历

示例：

```tsx
<ResumeRenderer
  schema={template.schema}
  styleConfig={template.styleConfig}
  data={template.previewData}
/>
```

---

## 5.2 页面要求

必须保证：

### 固定宽度

```css
width: 794px;
```

对应：

```text
A4
96 DPI
```

---

### 白色背景

```css
background: #ffffff;
```

---

### 无编辑器UI

禁止显示：

* 工具栏
* 拖拽按钮
* 编辑按钮
* AI按钮

仅保留简历内容。

---

# 六、截图服务实现

## 技术选型

使用：

```text
Playwright
```

原因：

* 稳定
* 截图质量高
* 支持 PDF 导出
* 支持无头浏览器

---

## 生成流程

### Step 1

打开预览页面

```text
/template-preview/:id
```

---

### Step 2

等待页面完成渲染

```ts
await page.waitForLoadState('networkidle');
```

---

### Step 3

等待字体加载

```ts
await page.waitForTimeout(1000);
```

---

### Step 4

设置视口

```ts
await page.setViewportSize({
  width: 1200,
  height: 1697
});
```

---

### Step 5

截图

```ts
await page.screenshot({
  fullPage: true,
  path: previewPath
});
```

生成：

```text
preview.png
```

---

# 七、缩略图生成

技术选型：

```text
Sharp
```

---

## 生成缩略图

```ts
await sharp(preview.png)
  .resize({
    width: 300
  })
  .webp({
    quality: 80
  })
  .toFile(thumbnail.webp);
```

输出：

```text
thumbnail.webp
```

# 九、生成时机

推荐：

模板创建后自动生成。

流程：

```text
创建模板
    ↓
保存数据库
    ↓
生成预览图
    ↓
生成缩略图
    ↓
上传对象存储
    ↓
更新URL
```

避免：

```text
用户访问时动态生成
```

原因：

* 性能差
* 成本高
* 用户体验差
